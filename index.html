How to use this template

\n Internal \u2014 not printed\n
\n
\n
    \n
  1. Start on the Project setup page: fill in the specification title, issuing company, project number, name, address, revision, date, contractor, sub-contractor, architect and GA contact, then press Apply to specification. Those values flow into the title page, running header and clauses and are saved with the document.
    2. \n
  2. Choose the manufacturer and board range on the same page. Only these two fields need changing to re-issue a specification against a different manufacturer; check any board names that differ between ranges (dB, Fire, MR, Standard, Coreboard equivalents).
    3. \n
  3. Use Choose a system from the library to pick a tested manufacturer system: set the schedule, narrow by family, filter on performance (for example \u201c60 minutes\u201d or \u201c54 dB\u201d), give it your project reference, then press Insert into schedule \u2014 the row lands in the matching table on tab 3. Anything not in the library goes in as a custom system below, which is saved for future projects.
    4. \n
  4. Complete the three schedule tables. Duplicate a row per type, use a full-width row for types removed from the specification, and put project comments in each table\u2019s Additional notes row.
    5. \n
  5. Press Generate full clauses from schedule to build one clause page per scheduled type. Anything the schedule cannot supply reads TBC \u2014 complete those by hand.
    6. \n
  6. Use + Add clause at the end of the clause section for anything extra, \u2212 Remove clause in a clause header to delete one, and Undo remove if that was a mistake.
    7. \n
  7. Drop or paste an image into each clause\u2019s build-up box (hover the box and press Ctrl+V). Double-click a filled box to move and resize the image.
    8. \n
  8. Add a row to the title-page revision table for every issue, and update the revision letter and date on the setup page.
    9. \n
  9. Press Save as new project at the top to create a fresh copy for the next job \u2014 each copy keeps its own images and project details. Export with Print / save PDF at A4 landscape; this page and all buttons are omitted from the print.
    10. \n
